## Описание программы

**Book Tracker** — это графическое приложение для управления списком прочитанных книг. Оно позволяет добавлять записи, фильтровать их по жанрам и страницам, а также удалять лишнее. Данные сохраняются в JSON.

---

## Возможности программы
* **Добавление книг**: ввод названия, автора, жанра и страниц.
* **Валидация**: проверка на пустые поля и числа.
* **Фильтрация**: поиск по жанру и количеству страниц (> 200).
* **Удаление**: возможность убрать книгу из списка.

---

## Как запустить
1. Установите Python 3.10+.
2. Скачайте проект и запустите:
   `python main.py`

---

## Примеры использования

### Добавление книги:
1. Заполните все поля формы:
    - **Название книги:** "Мастер и Маргарита"
    - **Автор:** "Михаил Булгаков"
    - **Жанр:** "Роман"
    - **Количество страниц:** 480
2. Нажмите кнопку **"Добавить книгу"**
3. Книга появится в списке внизу окна
